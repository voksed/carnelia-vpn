## Attribution

This project is based on [Amnezia VPN](https://github.com/amnezia-vpn/amnezia-client):
- Original VPN protocols and core logic
- Community-driven development model

However, Carnelia VPN provides:
- Modern Kotlin/Jetpack Compose UI (replacing Qt)
- Optimized for mobile-first approach
- Streamlined codebase (~90% lighter on UI layer)
